# OrthoVoix - Speech Therapy Management System

Complete speech therapy management platform with Docker deployment.

## 📁 Structure

- `backend/` - NestJS API
- `frontend/` - React PWA
- `docker-compose.yml` - Container orchestration

## 🚀 Quick Start

### Development
```bash
# Backend
cd backend
npm install
npm run start:dev

# Frontend
cd frontend
npm install
npm run dev
